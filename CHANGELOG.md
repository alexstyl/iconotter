# Changelog

## Unreleased

- Android: launcher instructions no longer say you need to compile against API 33; themed icons work with any compileSdk.

## 0.2.0 - 2026-11-02

- Backgrounds: use an image as the icon background with `--background pattern.png`, on every platform including macOS glass.

## 0.1.0 - 2026-11-02

- App icons: create Android, iOS, macOS, Windows, Linux and web icons from one SVG, PNG or JPEG.
- Notification icons: create Android notification icons from your artwork.
- Install: install with Homebrew, a download from GitHub Releases, or `go install`; `iconotter --version` prints the installed version.
